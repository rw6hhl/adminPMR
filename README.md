# Admin PMR

Приложение для управления каналом PMR (сервер `185.221.154.39`).

**Версия:** V2.6
**Платформа:** Android 7.0+ (minSdk 24, targetSdk 34)
**Имя APK:** `app-v2_6.apk`

---

## Назначение

Программа Admin PMR — мобильная панель для работы с сервером PMR. Показывает список абонентов в канале, позволяет банить и разбанивать их одним касанием, управлять доступом 26 региона к Ростовскому репитеру.

---

## Экраны программы

### 1. Splash-экран (приветствие)

Показывается при запуске 5 секунд. Синий фон. Крупная надпись «Admin PMR» и версия «V2.6». Автоматический переход дальше — в зависимости от настроек.

### 2. Экран проверки системы

Показывает параметры соединения:

| Параметр | Значение |
|---|---|
| Порт приёма | 5323 — СВОБОДЕН / ЗАНЯТ |
| Сервер PMR | 185.221.154.39 — ДОСТУПЕН / НЕДОСТУПЕН |
| Канал | хх |
| Секрет | хххх |
| Пароль | ВКЛЮЧЁН / ОТКЛЮЧЁН |
| Автозапуск | ОТКЛЮЧЁН |

Кнопка **«ПРОДОЛЖИТЬ»** — переход к следующему экрану. Автоперехода нет.

### 3. Экран ввода пароля

Показывается, если включена опция «Требовать пароль». Поле ввода пароля и кнопка **«ВОЙТИ»**.

Пароль по умолчанию: `ххххххх`.
